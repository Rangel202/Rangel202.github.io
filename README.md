## O que tem no site

- **Início** com circuito animado ao fundo e o fluxo interface → API → banco de dados ao vivo
- **Terminal interativo**: comandos como `help`, `whoami`, `neofetch`, `projetos`, `skills`, `infra`, `contato` e `sudo contratar`
- **Habilidades** por área: front-end, back-end, banco de dados, ferramentas, qualidade e suporte de TI
- **Infraestrutura**: rede animada e a experiência de 2 anos no TI da FuelTech
- **Projetos**: sites feitos para clientes, projetos acadêmicos e trechos reais de código
- **Repositórios**: lista dos repositórios públicos atualizada direto da API do GitHub
- **Trajetória**, currículo em PDF e contato por e-mail, WhatsApp e LinkedIn
- Três temas (azul noite, circuito e claro) e layout para computador e celular

## Tecnologias

HTML, CSS e JavaScript puro, sem frameworks e sem etapa de build.
Canvas para o circuito animado, SVG animado para a rede e a API pública do GitHub para a lista de repositórios.

## Como editar

Todo o conteúdo fica no bloco `PERFIL`, no começo do `<script>` do `index.html`.
Basta trocar os textos ali, salvar e enviar para o GitHub.

- Trechos entre `[[ ]]` aparecem destacados no site até serem preenchidos.
- Os prints dos projetos ficam na pasta `img/`.
- O currículo é o arquivo `curriculo-gabriel-rangel.pdf`.
- Novos repositórios públicos aparecem sozinhos na seção de repositórios. Preencha a descrição e o campo *Website* de cada um no GitHub.

## Estrutura

```
index.html                      página do portfólio
404.html                        página de "rota não encontrada"
curriculo-gabriel-rangel.pdf    currículo para download
img/                            prints dos projetos e imagem de prévia (og.png)
.nojekyll                       publica os arquivos como estão no GitHub Pages
```
